## Output

### 1. Solution Ideation – Crazy 8s

**Problem:** Users find it difficult to book hospital appointments quickly.

| Idea | Solution                             |
| ---- | ------------------------------------ |
| 1    | Quick appointment booking            |
| 2    | Search doctors by specialty          |
| 3    | Show available time slots            |
| 4    | One-tap appointment confirmation     |
| 5    | Appointment reminders                |
| 6    | Online consultation option           |
| 7    | Save favorite doctors                |
| 8    | Reschedule/cancel appointment easily |

### 2. User Stories

| No. | User Story                                                                                                           |
| --- | -------------------------------------------------------------------------------------------------------------------- |
| 1   | As a patient, I want to search for doctors by specialty, so that I can find the right doctor quickly.                |
| 2   | As a patient, I want to view available time slots, so that I can choose a convenient appointment time.               |
| 3   | As a patient, I want to receive appointment reminders, so that I do not forget my appointment.                       |
| 4   | As a patient, I want to reschedule an appointment, so that I can change it when my plans change.                     |
| 5   | As a patient, I want to receive confirmation after booking, so that I know my appointment is successfully scheduled. |

---

### 3. Narrative Scenario

**User:** A college student needs to consult a doctor.

The student is at home and suddenly experiences discomfort. They feel **worried and slightly stressed** because they need medical advice quickly. They open the hospital app, search for the required specialty, select a doctor, and check the available time slots. After choosing a suitable time, they confirm the appointment and receive a notification. The simple booking process makes the user feel **relieved and confident**.
